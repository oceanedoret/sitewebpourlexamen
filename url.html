Étape 2 · La ville

Les URL

Dans la ville du web, chaque page a son adresse. Apprenons à la lire comme on lit l'adresse sur une enveloppe, et découvrons ce que le serveur nous répond quand on frappe à sa porte.

Qu'est-ce qu'une URL ?

Une URL est une adresse qui permet de localiser une ressource sur Internet : une page web, une image, un document, une vidéo, etc. L'URL est l'identité d'un site internet ou d'une page internet.

Une adresse postale pour les pages web. Pour qu'une lettre arrive, il faut savoir comment l'envoyer, dans quel immeuble la déposer et dans quelle pièce la remettre. Une URL donne exactement ces informations à votre navigateur.

Comment se lit une adresse ?

Une URL se lit de gauche à droite, du plus général au plus précis. Cliquez sur chaque partie de l'adresse écrite sur l'enveloppe.

1

Le schéma (ou protocole)

Il indique comment le navigateur doit communiquer avec le serveur.

Le « s » de https:// veut dire que l'échange est sécurisé. Voilà pourquoi on voit presque toujours https://.

Pour se représenter C'est le moyen de transport de la lettre.

2

Le nom d'hôte (domaine)

C'est le nom qui permet de retrouver le site ou le service sur Internet. Décortiquons www.exemple.com :

  • www est un sous-domaine utilisé pour le site web. Il n'est pas obligatoire.
  • exemple est le nom choisi pour le domaine.
  • .com est l'extension, aussi appelée domaine de premier niveau.

Pour se représenter C'est l'adresse de l'immeuble.

3

Le chemin

Il permet d'identifier ce que l'on souhaite consulter sur le site. Il ressemble à l'organisation des dossiers et des fichiers d'un ordinateur, mais il ne correspond pas forcément à un vrai fichier : le serveur peut aussi créer la page au moment de la demande.

  • /accueil peut désigner la page d'accueil.
  • /contact peut désigner la page de contact.
  • /images/logo.png peut désigner une image.

Pour se représenter C'est l'étage de l'appartement.

4

Les paramètres

Ce sont des informations supplémentaires pour préciser la demande ou changer le contenu affiché. Ils commencent par un point d'interrogation ? et sont séparés par &. Chaque paramètre a un nom et une valeur :

  • lang=fr : le nom est lang, la valeur est fr. On demande la version française.
  • page=2 : le nom est page, la valeur est 2. On demande la deuxième page.

Chaque site décide comment il utilise ces informations : tous ne reconnaissent pas les mêmes paramètres.

Pour se représenter C'est le numéro de l'appartement.

En résumé

Dans l'URL Sur l'enveloppe
https:// Le moyen de transport
www.exemple.com L'adresse de l'immeuble
/blog/article.html L'étage de l'appartement
?lang=fr&page=2 Le numéro de l'appartement

Les codes de réponse HTTP

Un code HTTP est un nombre envoyé par le serveur à votre navigateur pour indiquer le résultat de sa demande. Ce code dit si la demande a réussi, si une redirection est nécessaire ou si une erreur s'est produite.

Le navigateur Peux-tu m'envoyer cette page ?

Le serveur Voici ma réponse, avec un code : 200 !

Les cinq familles de codes

  • 1xx Information La demande est en cours de traitement.
  • 2xx Succès La demande a été reçue et traitée avec succès.
  • 3xx Redirection Il faut aller chercher la ressource à une autre adresse.
  • 4xx Erreur de la demande La demande pose problème, par exemple une page introuvable.
  • 5xx Erreur du serveur Le serveur n'a pas réussi à traiter une demande pourtant valide.

À vous de jouer ! Grattez chaque carte pour découvrir la réponse du serveur.

200

Réponse du serveur

200 · OK

La demande HTTP a été traitée avec succès.

Exemple : vous ouvrez la page d'accueil d'un site et le serveur renvoie correctement le contenu demandé.

Cela ne garantit pas que tout le site fonctionne parfaitement, seulement que cette demande a réussi.

Côté poste La lettre est bien arrivée.

200 = la demande a réussi.

404

Réponse du serveur

404 · Not Found

Le serveur n'a pas trouvé la ressource qui correspond à l'URL demandée.

Exemple : vous cliquez sur un lien vers /portfolio/photo.jpg, mais cette image n'existe pas à cette adresse.

La page a pu être supprimée, l'adresse est peut-être mal écrite ou le lien pointe vers une mauvaise URL.

Côté poste Destinataire introuvable à cette adresse.

404 = la ressource est introuvable.

500

Réponse du serveur

500 · Internal Server Error

Le serveur a rencontré une erreur inattendue qui l'empêche de traiter la demande.

Exemple : vous ouvrez la page de contact, mais une erreur dans le programme du site empêche le serveur de créer la page.

Le visiteur ne peut généralement rien y faire : c'est à la personne qui gère le site de régler le problème.

Côté poste Le bureau de poste a un problème interne.

500 = le serveur a un problème interne.

Les redirections 301 et 302

Parfois, une page a changé d'adresse. Le serveur répond alors avec un code de la famille 3xx et indique la nouvelle URL. Le navigateur s'y rend tout seul, sans que vous ayez rien à faire. Tout dépend de la durée du déménagement :

301

Réponse du serveur

301 · Moved Permanently

La ressource a été déplacée définitivement vers une nouvelle URL. Les moteurs de recherche remplacent l'ancienne adresse par la nouvelle.

Exemple : un site passe de http:// à https://, ou renomme sa page /contact.html en /contact.

Côté poste Le destinataire a déménagé pour de bon : on fait suivre le courrier et on met à jour son carnet d'adresses.

301 = déménagement définitif.

302

Réponse du serveur

302 · Found (Temporary Redirect)

La ressource se trouve temporairement à une autre URL. L'ancienne adresse reste la bonne : les moteurs de recherche la gardent.

Exemple : pendant une maintenance, la boutique d'un site renvoie ses visiteurs vers une page « Revenez bientôt ».

Côté poste Le destinataire est en vacances : son courrier est réexpédié quelques jours, puis il revient chez lui.

302 = déménagement temporaire.

À retenir

  • Une URL est l'adresse d'une ressource sur Internet. Elle se lit comme une adresse postale.
  • Elle se compose d'un schéma, d'un nom d'hôte, d'un chemin et parfois de paramètres.
  • Le serveur répond toujours avec un code : 200 = succès, 404 = introuvable, 500 = erreur du serveur.
  • Une redirection 301 est définitive, une 302 est temporaire.
